# 삐약이 — 대화로 키우는 다마고치형 AI 챗봇

채팅할수록 알에서 병아리로, 병아리에서 닭으로 자라는 AI 캐릭터입니다.
어떻게 대해주느냐에 따라 **전혀 다른 모습으로 진화**합니다.

🔗 **직접 키워보기:** https://vibe-chick.vercel.app

> ⚠️ 무료 API 한도로 응답이 지연되거나 일시적으로 실패할 수 있습니다.
> 화면과 진화 단계는 아래 이미지로 확인하실 수 있습니다.

## 숨은 진화

Lv.5에 도달하는 순간, 그때까지 어떻게 키웠는지에 따라 **다른 형태로 갈라집니다.**

| <img src="public/angel.png" width="110"> | <img src="public/dark.png" width="110"> | <img src="public/phoenix.png" width="110"> |
|:---:|:---:|:---:|
| **천사 삐약이** | **흑화 삐약이** | **불사조 삐약이** |
| 기분을 좋게 해주고 애정을 많이 준 경우 | 부정적인 말을 많이 들은 경우 | 한 번 떠나보냈다가 다시 키운 경우 |
| 따뜻하고 포용적인 말투 | 삐딱하고 시니컬한 츤데레 말투 | 재에서 돌아온 전설 |

이 밖에도 아직 공개하지 않은 형태가 하나 더 있습니다.

## 말투가 달라집니다

캐릭터의 상태가 **그때그때 시스템 프롬프트로 조립되어** 모델에 전달됩니다.
같은 질문을 해도 지금이 병아리인지 황금닭인지, 얼마나 친해졌는지, 어떤 형태로 진화했는지에 따라 답이 달라집니다.

- **진화 단계** — 어린 병아리의 호기심 많은 톤에서 황금닭의 여유로운 톤까지
- **친밀도** — 서로 잘 모르는 사이 → 제법 친해진 사이 → 단짝 → 가족 같은 사이
- **기분** — 사용자의 말에서 부정적인 표현을 감지해 기분 수치에 반영
- **숨은 형태** — 천사와 흑화는 같은 말에도 정반대로 반응

## 만든 이유

AI 채팅은 대부분 한 번 쓰고 닫습니다. **다시 열어보게 만들려면 무엇이 필요한지** 알아보려고 만들었습니다.
답변 품질을 높이는 대신, 캐릭터에 상태를 부여하고 그 상태를 프롬프트에 녹이는 방향을 택했습니다.
사내 개발 교육 스터디(2026.03~05)에서 AI 도구를 활용해 기획부터 배포까지 직접 진행했습니다.

## 기술 스택

- **Next.js 16** (App Router) · **React 19** · **TypeScript** · **Tailwind CSS 4**
- **Vercel AI SDK** — 토큰 단위 실시간 스트리밍 응답
- **Google Gemini** (`gemini-2.5-flash-lite`)
- 상태는 브라우저에 저장되어 다시 들어와도 이어서 키울 수 있습니다
- 모델 호출은 서버 라우트(`app/api/chat/route.ts`)에서 처리하고, API 키는 환경변수로만 관리합니다

## 로컬 실행

```bash
npm install

# .env.local 에 API 키 설정
# GOOGLE_GENERATIVE_AI_API_KEY=...

npm run dev
```

http://localhost:3000 접속.

## 배포

Vercel에 연결해 배포합니다. 환경변수(`GOOGLE_GENERATIVE_AI_API_KEY`)를 프로젝트 설정에 등록하면 됩니다.
